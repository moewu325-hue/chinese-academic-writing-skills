# 正式提交要求与AI使用声明

只在投稿、学位论文提交等正式任务按需读取。普通片段直接完成正文。

## 要求记录

复用当前任务已核实的目标单位、稿件类型、提交阶段与正式要求。个人措辞偏好、学科惯例、学校或期刊的硬性要求分别注明。正式要求记官方来源、适用范围、版本与核验日期；目标、阶段或要求变化时重核，缺少影响提交的关键信息时才问。示例论文用于理解文体，不自动成为强制模板。

根据实际要求确定可用的辅助范围及披露位置。已核实禁止的AI使用范围不生成相应提交稿；可继续整理要求、核实来源及提供适用的审阅帮助。没有取得目标正式要求时，记录具体未核项，不声称已符合该单位规范。法规与机构规则落地时核对当时官方版本，本页不常驻维护大学政策清单。

## 中英文声明模板

目标要求披露时生成，或按用户明确请求提供。以下方括号只填实际确认的事实；删除不适用部分，缺字段先保留缺项。工具版本只写可见信息；人工核验步骤由用户确认，不能自动填导师审核或全文核查。

**中文：**

在本稿的[准备阶段]，使用[工具名称及可见版本信息]辅助[实际用途]，涉及[具体章节／段落或处理范围]。实际完成的人工核验包括[已确认的核验内容与方式]。[按目标要求补充的留痕位置或使用日期]。

**English:**

During [stage] of preparing this manuscript, [tool name and available version information] was used to assist with [actual purpose] in [specific sections or scope]. The human verification completed consisted of [confirmed checks and methods]. [Records or dates required by the target venue].

以上是可填写的事实模板。正式措辞、责任声明与放置位置按目标单位当时要求调整；未确认的审核行为不写成已完成。

## 不采用的改稿手法

| 手法 | 本包不采用的理由 |
| --- | --- |
| 加错别字、零宽字符或格式噪声 | 引入错误及隐藏字符，增加检索、排版与后续编辑负担 |
| 强塞口语、经历、情绪 | 改变语域，可能补入作者没有提供的内容 |
| 同义词硬替换 | 容易改变术语、范围和主张强度 |
| 打乱句序 | 可能改变条件覆盖、时间关系和论证次序 |
| 中英回译 | 多增加一次含义迁移，逐处保真仍须重核 |
| 换模型重写全文 | 超出普通润色的局部授权，扩大需要核对的范围 |
| 一键改写工具 | 不自动上传稿件或接受其重写结果；当前任务采用可定位的局部编辑 |

这些是与中文学术目标有关的取舍理由，不把它们宣传为身份判别或检测效果结论。表达改善依据原材料、真实关系与当前任务的文体与用户要求。
