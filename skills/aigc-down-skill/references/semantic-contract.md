# 语义保真约定

适用于起草、润色、结构重写与审阅。先确定授权范围；起草中的材料缺口不等于补造权限，润色中的证据疑问不等于撤回作者主张的权限。

## 保护单元

按“位置＋命题/关系”核对，不以段号或锚点存在代替核对。一段可含多处问题。同一命题跨句出现时仍按其真实范围比较。每个对象分别满足某条件，不等同于几个行动者合计覆盖对象集合；核对量词和属性的作用层级。

| 保护内容 | 要核对的关系 |
| --- | --- |
| 事实与作者立场 | 谁提出什么；独立评价、研究经历、工作量判断是否已有依据 |
| 否定与量词 | 尚不能、未发现、非、仅、全部、任一、部分的极性及约束对象 |
| 数量与统计 | 对象—数值—单位—指标—条件；比较基线、分组、方向和显著性 |
| 关系 | 相关、因果、解释、先后、并行、包含、对比及其证据范围 |
| 限定与强度 | 可能、倾向、一定条件、频率、概率、可适用范围；不可擅自加强或削弱 |
| 时间与状态 | 计划、进行中、完成、观察到、拟验证等状态及时间窗 |
| 指代 | 名称—属性—行为—引文的映射；附近所有竞争对象 |
| 引用支持 | 哪个来源支持哪个命题，版本与读到的内容；引用键原样存在仍可能错绑 |
| 技术内容 | 定义、符号、公式、数据、路径、图表与交叉引用关系 |

## 修改边界

普通润色允许调整语序、断句、消除完全重复的表达，保留命题和必要语用功能。不因“显著、有效、重要、可能”等字眼自动改强或改弱；统计意义、作者评价与表达包装分别判断。

完全重复且没有独立限定或评价的包装可以精简。行为否定与目的否定分别核对，不能把“不以某行动为目的”无声改成“不做该行动”。作者独立的理论贡献、数据作用、价值判断、限制或结论属于内容；抽象不是无内容的充分证据。有证据疑问时在正文外提出，不能无声删掉、改成更弱主张，也不能补出所谓“可检验推论”。

原文的“不做A”不能推出“做B”，“未发现差异”不能改成“没有差异”，“先A后B”不能改成“A导致B”。多个否定若各约束不同命题，不能合成一句“存在局限”。条件从一句拆出后，要确认它仍约束所有原有动作。

不能补造数据、DOI、研究空白、工作经历、惊讶、犹豫、案例、机制或时间先后；不能删除不方便改写的第四项。现有材料不足时，保留必要内容，定位缺口。授权的内容扩充须有可核验依据，区分已有内容与新增建议。

## 逐处回读

对原稿和改稿逐项回答：主体和对象是谁，断言是什么，在哪些条件下成立，强度与状态是什么，由什么支持？数字和引文应与对应对象及命题一起读。仅查数字集合、锚点、词频或黑名单无法回答这些问题。

发现原稿矛盾时核实上下文；无法判断以哪一处为准就报告位置，不优先迎合较早摘要。修复后再比较；遇到模糊指代不能按“最近名词”猜映射。

## 判定与证据

- **FAIL（保真）**：未授权的命题、极性、条件、强度、状态、对象归属或引用支持变化；定位原片段与改片段并说明变化。
- **FAIL（任务约定）**：违背当前项目明确要求；必须列出该要求，不能把某篇论文口径推广为通用真理。
- **REVIEW（表达/缺口）**：表达可改、证据待核、指代未明，或规则命中但有合理保留情形；不把它伪装成语义失败。
- **PASS（本次比较）**：在可读取材料与检查范围内未发现变化；它不证明普遍保真。

做发布验收时，将错误改稿与等价改稿都交给审阅者，输入不包含标签、修改答案或预期判定。先冻结独立输出，再用标签评分。逐处标注而非只报整段FAIL；表达建议不得拖累等价改稿的语义通过。
