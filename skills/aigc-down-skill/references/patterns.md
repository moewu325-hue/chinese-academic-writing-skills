# 原16类模式：按功能审阅

编号沿用旧入口以便查历史记录。它们是可观察的表达提示，不是AI作者身份证据。新增的六项行文规则以chinese-prose.md为准，本表提供细部检索。

| 模式 | 定位提示 | 动作与保留条件 |
| --- | --- | --- |
| 1 泛化意义/展望 | 结尾通用价值替代实质内容 | 按S4区分包装、已有作者评价与独立推论；不编展望代替 |
| 2 重复总结 | 综上、由此可见重复刚说的信息 | 精简完全重复；必要总结、论证收束保留 |
| 3 模板问题宣告 | 每段“核心问题是” | 按S3用已有问题或材料展开；真正问题陈述可保留 |
| 4 模糊归因 | “研究表明”没有可定位来源 | 查提供材料；缺出处列为待核，不编引用或改成作者立场 |
| 5 编号逻辑 | 首先/其次/再次整齐排列 | 按S2核对内容与关系；真实步骤、枚举和多条理由保留 |
| 6 填充与限定 | 值得注意/潜在地/某种程度堆叠 | 区分话语包装与独立范围；不以“每句只能一个限定”删信息 |
| 7 案例升华 | 此案例印证了/这提示我们 | 按S4保护真实案例结论与作者判断，不补因果解释 |
| 8 决策包装 | 该处理体现了/该设计基于 | 材料有理由才说明；不编研究者曾失败、调整或反思 |
| 9 三元对称 | 等长三项反复出现 | 保留各项，按已有关系组织；真三分类和并行对照保留 |
| 10 理论起笔 | 多段依据某理论开头 | 按S3检查段落任务；定义与理论阐释需要时保留，不编观察 |
| 11 系动词堆砌 | 作为载体/扮演角色绕主干 | 能保持判断范围则简写；真实功能差异不能一律改“是” |
| 12 泛化词密集 | 见下列定位词表 | 先看语义；学科术语、统计显著与作者独立评价不自动替换 |
| 13 固定三步走 | 每段经济/社会/文化等固定框架 | 按S2/S3查任务；完整框架和规范要求保留，不删某维度 |
| 14 对仗排比 | 宣告创新、填补、丰富等 | 已有贡献按证据交代；不增研究空白或价值，不自动撤回立场 |
| 15 加粗密集 | 正文几乎每句突出几个词 | 无格式要求时精简视觉强调；标题、定义、模板和无障碍要求保留 |
| 16 标点驱动 | 冒号/破折号反复串层次 | 按S1读主干、条件和关系；不强制添加或禁用某个标点 |

定位词表：深刻揭示、具有重要意义、综合运用、不可或缺、深入探讨、系统梳理、提供了理论支撑、有效解决、完善了理论体系、充分说明、进一步、值得注意的是、需要指出的是。按短语实例数计；引用或讨论该词本身不计。

## 表达闸门＋豁免注记

“命中”表示交付前必须处理或作出可核对的保留决定，状态为REVIEW；未经判断的字面命中不能判语义FAIL。审阅/验收报告列位置、规则、实际动作或豁免理由；普通交付不强制输出表。计数对象为可读正文，排除题名、标题、参考文献、公式代码、直接引语及规则举例。

| 定位阈值 | 默认处理 | 豁免条件 |
| --- | --- | --- |
| 定位词表实例 >2/段 | 检查是否泛化、重复，改无独立信息的包装 | 术语/必要方法名、统计含义、独立作者主张或真实推进关系 |
| 整齐三元并列 >1/段 | 回读项目内容和真实关系 | 完整分类、方法变量、规范框架或确需并行比较 |
| 正文加粗 >5处 | 核对视觉层次并精简 | 用户格式、期刊模板、定义强调或其他明确功能 |
| 无独立内容的泛化结尾 >0处 | 精简，保留本段完成的信息 | 实为作者独立评价、必要结论或有依据的推论时不计 |
| 重复总结套句 >1处/全文 | 查是否重复、可压缩 | 章节总结、跨节回顾或用户要求的必要总结 |
| 理论名称起段 >20%段落 | 查是否每段只复述主题句 | 理论/概念章、定义解释、规定结构与承重主题句 |
| 未定位来源的模糊归因 >0处 | 标记证据缺口并核已有材料 | 已在上下文绑定来源则不计；无来源时不直接编引用或改作者归因 |
| 冒号串联 ≥3次/段或破折号 ≥4次/段 | 核查主干和层次，可断句 | 定义、规范清单、原样引用或文体要求明确且易读 |

长句、四项名词、前者/后者、否定句没有一刀切数量上限；按六项规则的功能条件检查。92%—108%篇幅报警不覆盖事实、限制或独立评价，不能用灌水补回。

## 例：只消除同义包装

原文：本次仅纳入公开记录。纳入范围限定为公开记录。

改稿：本次仅纳入公开记录。

“仅”继续约束纳入范围；删去的是同一命题的重复，没有补入数据、用途或原因。若第二句另有时间或样本限定，则不能照此删除。
