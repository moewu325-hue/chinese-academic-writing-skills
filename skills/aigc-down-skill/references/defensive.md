# 模式17：防御性表达与必要边界

与六项规则S6共同使用；本页帮助区分功能，不设置否定词黑名单。

学术正文回读时，先看章节是否沿对象与理论、概念与问题、材料与操作、发现与解释展开。逐条防御的症状是：段落主要任务变成排除误解，证据与发现尚未展开，便连续说明“不做什么、不能推出什么”；同一边界换动词后又在后节出现。将真实审稿问题留在答复稿逐项处理，正文用正面材料与推理完成对应修改。

按功能处理：重复免责合并；证据能力写清“已支持到哪步、目标推断需要什么”；材料缺项写明字段和所查范围；研究范围按实际材料与设计交代。真实否定发现与独立排除项保留，其肯定式改写以语义等价为条件。改后仍须回答谁做了什么、依据是什么、支持到哪一步；不能用“需要研究”笼统替换各项独立限制。

逐句定位所否定的命题与对象：研究没有发现什么、没有测量什么、不能推出什么、实际排除什么、回应谁的哪项质疑？这些内容各自独立时保留。连写三个否定也可能完全必要。

同一限制重复预防相同误解时，可以合并表达。材料已说明正向任务时，先交代实际任务，再就近保留必要排除。仅有否定而没有正向任务的材料，不能补一个“转向B”；也不能把“不能证明因果”改成关联已经成立。

区分“这项研究不是万能的”等无命题包装与具体的适用范围。前者仍需确认是否承担作者独立立场；后者即使读来防御也属于保护内容。“不能”“尚未”“仅”不可因为语气不够果断而删除。

有效边界贴近它约束的主张。跨章、摘要或单独流通片段有再次声明的需要时，不以全文只留一处压掉边界。审稿回复可以直接回答真实质疑并说明已改动作；没有发生的改动、追加实验或修正证据不得写成已经完成。

审阅结果分别记保真与表达；只有未经授权的主张变化才属于保真FAIL。证明某项免责重复，需要说出它与哪一命题等价，不能只数“不”字。
