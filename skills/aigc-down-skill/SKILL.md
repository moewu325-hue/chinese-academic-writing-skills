# 中文学术修订

保留已有名称；执行版本 `2026-10-20.1`。适用于各学科的中文学术稿，也可用于已有普通中文文字的润色。目标是准确、清楚、符合文体，不承诺检测率、作者身份或投稿结果。

## 进入任务

用户已经要求润色或直接改写时，直接执行；只审阅则不改正文。不要求检测报告或再次确认。局部润色不自动授权改章节结构、补研究内容或校准作者主张。起草新内容、重组论证使用 `research-writing-skill`；查文献或核出处使用 `academic-researcher`，不自动将小段润色扩大为检索任务。

执行中文修订前，用当前宿主的文件读取工具**完整读取**：

1. [语义保真约定](references/semantic-contract.md)。
2. [六项中文行文规则](references/chinese-prose.md)。

相对路径均以本文件所在目录为基准，不按终端工作目录猜路径。只读了入口、摘要或规则名称，不算加载正文。资源不可读时说明具体缺失，不声称已应用完整技能。

## 修订步骤

1. 从已提供的原文、上下文和作者约定确定保护内容；有多个可能的指代对象时先核对材料，无法确定就定位疑问。
2. 根据段落任务执行S1—S6：在层次转换处分句；从已有动作展开名词串列；按任务决定起句；信息完成后停住；核实比较对象；按论证组织正文，合并逐条防御式的重复免责，等价改写为材料范围、依据停点或所需证据，保护真实否定结果与独立限制。
3. 完整论文润色、旧16类审阅或需要更细的词语句式检查时，完整读取 [原16类模式及闸门豁免](references/patterns.md)。连续防御性表达或限定词难以分类时读取 [模式17](references/defensive.md)。长稿、术语、公式或源文件读取 [格式与连续性](references/conventions.md)。整节、整篇稿件或明确要求审阅时，依该页运行 [同一个检查器](scripts/check_tells.py)；小段润色直接交付正文。正式提交任务按需读取 [提交要求与声明](references/submission.md)，复用已有要求。
4. 逐处比较原稿和改稿的命题、归属、范围与引用，再回读六项。删除句子前须确认它与已保留命题等价，且无独立的作用、贡献或价值判断；无法确认时保留并定位疑问，不能先删再说“如视为独立评价可恢复”。允许零修改。已启用的表达闸门命中都应有处理或明确保留理由；未加载的细审项目不声称已通过；不得靠删独立内容、编经历、强换句式达到阈值。

## 交付与篇幅

交付内容是用户要求的修订正文；确有无法确定的事实或指代时，另列原位置和具体疑问。用户未要求审阅报告时，不逐项解释已改操作，不附假设式回填、评分或六项表。随附材料已澄清的对象直接写明，无须再请用户确认。

普通保量润色以原可读正文计，同一口径的长度比在92%—108%外触发回读，低于90%优先核查漏删。需要报告长度比时用真实计数工具按同一口径核算；未计量就说明未计量，不填猜测数字。它是报警区间，不是靠补字或强删达标的配额；纯重复精简后信息完整可说明保留。摘要、明确压缩、扩写、翻译及重新组织内容按用户目标执行。

保真失败须修复或定位未解决项；表达问题可修改，也可基于文体与功能保留。机械PASS只证明已检查的项目，不是语义等价证明。规则来源和取舍见 [来源](references/sources.md)。
