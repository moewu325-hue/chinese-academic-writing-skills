# 学术文体分支

先依据目标学校、期刊或用途的具体要求选择结构；下列是段落任务提示，不是统一模板、章节数量或句式配额。用户已有内容、研究贡献及限定优先。

| 文体/部位 | 组织依据与检查 |
| --- | --- |
| 摘要 | 围绕研究问题、实际方法与主要结果交代必要信息；没有结果时不能假写。结果或答案可在前，不固定先铺背景 |
| 引言/理论论证 | 用已有材料形成问题与论证；定义、前提、推理和反例按需要展开，不编研究空白或强套假设实验结构 |
| 方法 | 说明已给的对象、操作、变量、条件与可复现细节；区分并行与顺序、每个对象的要求与总体覆盖，不补未交代的参数和行动者 |
| 结果/讨论 | 数量、方向、比较基线和不确定性随原结果；相关不改因果、未显著不改无差异。解释、意义和机制有依据才起草，已有作者评价不可无声撤回 |
| 叙述综述 | 按主题、问题、方法或争议综合已读取内容；比较同一维度，标明版本、条件与分歧，不以仓库或论文票数制造共识 |
| 系统综述 | 只有实际开展了检索、筛选、评价才能写相应方法与数量；PRISMA等按目标要求使用，不补筛选流程或称穷尽全部文献 |
| 开题/研究计划 | 明确拟解决的问题、已有依据及计划，拟做与已做分开；不能把预期结果当作完成证据 |
| 基金/正式申报 | 先读取当前年度和目标机构指南与用户要求，再选择结构、篇幅和表达；不凭通用经验推定所有项目的最新限制 |
| 审稿回复 | 对实际意见答复，依据已有修改说明位置；未完成实验或修正只能写计划，不能承诺成已完成。真实拒绝理由和独立边界保留，合并重复防御 |
| 普通学术解释 | 全篇及时回答问题，按理解需要展开材料和推理；无需把短答变成论文章节或引入未要求的综述 |

中文学术语域以准确、清楚为准，保留适合本学科的作者视角；不按人味配额添加口语、成语、犹豫或惊讶。公式、变量、术语和引文随正文关系核对，版式要求不能授权改研究内容。
