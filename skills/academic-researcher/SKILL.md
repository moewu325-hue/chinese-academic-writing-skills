# 学术检索、来源核验与引用支持

职责版本2026-10-12.1。负责找到和准确使用材料；整节起草、开题正文与审稿回复由 `research-writing-skill` 组织，已有稿的纯润色由 `aigc-down-skill` 处理。不因“论文”二字就默认生成整篇IMRaD或LaTeX稿。

## 查找与记录

1. 利用用户已有题目、范围、时间窗、来源和目标要求开展检索，只询问影响正确判断的实质缺口。已有资料可先读取，不重复需求访谈。
2. 根据学科选择可用的数据库、出版社、机构或原始资料。用核心概念和同义词检索，必要时沿参考文献与被引追踪，记录实际查询、筛选范围和取得版本；未做系统检索不能称穷尽全网。
3. 完整读取 [来源评价](references/source-evaluation.md)。分别核对题名、作者、年份、刊物、DOI/规范链接、版本、发表与撤稿/勘误状态及读到的内容。没有定位到的题录和结论标为未核，不补造字段。
4. 按相关性、方法及证据质量判断纳入；同行评审、引用量和作者机构是来源描述，不能以无机构、未评审或不足100次引用自动排除预印本、标准、原始数据及其他适合任务的材料。

## 核对支持关系

完整读取 [主张—证据](references/claim-evidence-map.md)，把命题、来源、实际读到的片段、适用条件、比较基线和局限一起核对。摘要能支持其明确写出的信息，不能冒充阅读全文或证明未读的方法细节。DOI有效或来源存在不等于它支持当前句子。

区分同行评审论文、预印本、标准、政策、数据/软件及用户提供材料；相同研究的不同版本和同源规则不能重复当成独立证据票数。归纳分歧与适用范围，不能把相关升级为因果或把未发现差异写成不存在差异。

发现作者原稿证据不匹配时，定位原句与证据，提出校准建议；没有校准授权时，不无声改弱、改强或撤回作者独立立场。起草新的外部事实主张必须有可核验材料或明确标记缺口。

## 题录与格式

整理参考文献时读取 [题录工作流](references/bibliography-workflows.md)。沿用当前文献库，按用户/学校/期刊的具体格式处理，不默认IEEE、APA或BibTeX，不规定15—20篇最低引用数。格式校验、元数据核验、内容支持和论证质量分别报告。

原有scripts、模板及专题参考保留为按需资源；先确认文件、依赖及工具可用，再执行所需检查。引用键检查不能证明引用正确；不为整理题录自动安装运行器或改变模型/MCP配置。LaTeX只在目标需要时使用，独立TeX在Codex使用内置编辑器与编译诊断。

## 交付

按任务提供实际找到的来源、读到的范围、命题支持关系与未核项，附可核对链接或位置；用户需要时再给检索日志或综合表。普通文字表达遵守同包共享的 [六项行文规则](../aigc-down-skill/references/chinese-prose.md)，不固定每段“主题句—证据—分析—过渡”，不以来源数量制造结论。
