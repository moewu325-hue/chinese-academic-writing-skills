# 来源评价与核验

按任务的证据需要选来源，先区别来源类型，再评价它实际支持什么。

- 同行评审论文：核实相应版本和发表状态；不能把预印本直接称为已评审。
- 预印本、标准、机构政策、数据、软件、历史原始资料：可以纳入适合的任务，准确标注其类别、版本和证据用途。
- 用户提供材料：可作为当前写作材料，但未独立查证的元数据不能写成已经核实。

核对规范来源记录：题名、作者、年份、刊物或机构、卷期页码（存在时）、DOI或规范URL；缺少字段就保留缺项，不猜。需要当前状态时查询出版方或权威记录的勘误、撤稿与新版信息。记录阅读范围为全文、摘要、图表或题录；只读摘要不能声称已核实验方法。

评审制度、刊物记录、引用量及作者身份可作为核查线索，不能单凭无机构、引用少或未评审判定不合格。评估研究问题相关性、方法适切性、数据来源、结果条件与局限。质量信号有缺口时指出具体缺口；不靠声誉替代内容核验。

无法取得全文时先查出版方开放版本、机构仓储或作者公开稿。已有摘要可支持它明示的信息，不凭摘要编细节；关键未读内容列为缺口。不得绕开访问控制获取付费文献。

记录各版本和共同研究/数据关系。预印本与发表稿可比较差异，不能算两项独立研究；多个仓库引用同一规则也不能当多票独立验证。判断独立性须有证据，未致谢不等于独立，交叉链接不等于继承。
