# 题录与参考文献工作流

沿用用户当前文献库或参考文献表作为唯一维护入口。只有任务使用BibTeX/BibLaTeX时才以相应bib文件为主，不为普通Word稿强制转换。格式优先取当前学校、期刊、出版社或用户的具体要求；需要最新标准时先核权威版本。

1. 核对作者、题名、年份、刊物/出版机构、页码及版本，缺项列明，不拼凑。
2. 有DOI则保存并核其指向同一作品；没有DOI的标准、原始资料或数据可用规范链接。URL、DOI、访问日期等字段按目标格式保留。
3. 消除同一作品重复条目，保留预印本与发表稿的对应关系，必要时标明实际引用版本。
4. 正文引用与题录一一核对，包括引用实际支持的命题；出处存在不能代替内容匹配。
5. BibTeX任务中保持稳定引用键，保护题名中的专有名称，沿用现有编译系统与样式，不自动更换BibTeX/biber。

检查结果区分：格式合规、键一致性、元数据真实、实际阅读范围、命题支持。脚本只能对它支持的字段与范围作结论；未查全文不可声称引用内容已全面核实。原有脚本先查帮助与依赖，再在任务需要时执行，不为技能配置安装新依赖。
